# 学习笔记目录

## 记笔记的规则
1. **一个阶段一个文件**，按课程顺序编号。
2. **每个知识点固定 6 栏**：
   - 是什么：一句话说清楚
   - 解决什么问题：为什么需要它
   - 比喻：方便记忆
   - 常用命令 / 代码：只记最常用的
   - 踩过的坑：自己真正遇到的报错和解决办法
   - 我的理解：**必须自己写**，写不出来说明还没懂
3. **导师负责整理前五栏，"我的理解"由我自己填。**
4. 看笔记时先遮住内容，试着回忆，回忆不起来再看。
