# my-shopmate

跨境电商售后客服 Agent（ShopMate），在 AI 导师指导下从 0 到 1 亲手重写。

## 目录结构

| 路径 | 用途 |
|---|---|
| `main.py` | 项目入口 |
| `data/` | 模拟数据（订单等） |
| `practice/` | 每课练习：`lessonN.py` 是跟练，其余是作业 |
| `notes/` | 学习笔记，规则见 `notes/README.md` |
| `CLAUDE.md` | 给 AI 导师的交接说明和学习进度 |

## 运行

```bash
uv run main.py
```
